## 🎨 Clean Minimal Executive Aesthetic
Redesigned with a focus on simplicity, high readability, executive credibility, and zero visual clutter.

* **Primary Accent Color:** Crimson Rust (`#C0392B` / `#BA372A` — exact match to user color swatch)
* **Backgrounds:** Deep Pure Black (`#0A0A0A`) & Refined Charcoal (`#141414`)
* **Typography:** `Plus Jakarta Sans` for clean, professional modern typography & `JetBrains Mono` for code
* **Design Philosophy:** 
  - Uncluttered, clean grid structure
  - No noisy scanlines or artificial sound effects
  - Subtle, calm ambient particle depth in the background
  - Clear, readable typography and comfortable breathing room
  - Straightforward recruiter navigation and 1-click contact actions

## 🚀 How to Run Locally

### Option 1: Direct File Open
Double-click `index.html` to open it in Chrome, Edge, or Safari immediately.

### Option 2: Python HTTP Server
```bash
python server.py 8080
```
Open `http://localhost:8080` in your browser.
